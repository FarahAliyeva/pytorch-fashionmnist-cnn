# PyTorch FashionMNIST CNN

A complete notebook for building, training, and evaluating a **Convolutional Neural Network (CNN)** on the FashionMNIST dataset using PyTorch.

This notebook implements a TinyVGG-style architecture and compares predictions against ground-truth labels.

## What's included

- Loading and exploring the FashionMNIST dataset
- DataLoaders for training and testing
- Building a CNN model (`model_2`)
- Training loop with loss and accuracy tracking
- Making predictions on the test set
- Visualizing predictions (green = correct, red = incorrect)
- Saving the trained model
